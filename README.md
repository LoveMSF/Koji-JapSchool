# コウジ | Кодзи — Школа японского языка

Адаптивный лендинг онлайн-школы японского языка «Кодзи», выполненный в минималистичной японской эстетике (*Yohaku* — искусство свободного пространства).

## Что внутри
- **Главный экран:** оффер, статистика учеников (`1 200+`) и быстрый переход к курсам.
- **Программы обучения:** карточки направлений («С нуля», «Живой японский», «Подготовка к JLPT N5–N2») с ценами.
- **Метод Кодзи:** 3 принципа обучения, бегущая строка и отзыв студента.
- **Запись на урок:** форма/кнопка для заявки на бесплатное пробное занятие.

## Стек
- HTML5, CSS3 (Flexbox / Grid), JavaScript *(замени на свой стек, если использовал фреймворки)*

## Запуск локально
```bash
git clone 
cd koji-school
```
Открой `index.html` в браузере (или запусти через `npm run dev`, если используешь сборщик).
